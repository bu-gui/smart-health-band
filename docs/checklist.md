# SmartHealthBand App 检查清单

> 用于开发测试、发布前验证和日常维护。每完成一项把 [ ] 改 [x]。

---

## 1. 蓝牙连接（BLE）

- [ ] Android 蓝牙扫描/连接权限 + 位置权限（Android 10+）
- [ ] iOS 蓝牙权限配置
- [ ] 扫描只显示 "SmartHealthBand" 设备
- [ ] RSSI 信号强度正确显示与分级
- [ ] 点击设备连接成功，显示设备信息（型号/固件/硬件/序列号）
- [ ] 断开后状态重置
- [ ] 意外断开自动重连（5s→10s→20s，最多 3 次）
- [ ] 指令发送成功：reset_steps / set_page / sync_time / start_measure / stop_measure

## 2. 健康监测

- [ ] 心率/血氧/步数/运动状态/信号/电量实时更新
- [ ] 心率无效(0)显示 `--`，不显示"异常"
- [ ] 血氧 <95% 警告、<90% 严重警告
- [ ] 步数目标进度条/百分比计算正确
- [ ] 低电量警告（≤20%）

## 3. 跌倒告警

- [ ] 收到 fall=true 全屏弹窗 + 震动 + 声音
- [ ] 3 秒去重（避免重复弹窗）
- [ ] "我没事"可关闭，"紧急求助"触发求助流程
- [ ] 本地通知：标题「⚠️ 检测到跌倒！」含时间和心率

## 4. 数据分析

- [ ] 24h/7d/30d 切换，数据重新加载 + 加载动画
- [ ] 心率趋势折线图（正常范围参考线，平均/最低/最高）
- [ ] 血氧趋势折线图（<95% 标红，平均/最低）
- [ ] 步数柱状图（日/周/月 + 目标线）
- [ ] 今日健康报告（平均心率/血氧/总步数/运动时长/跌倒次数/最低心率）
- [ ] 异常事件列表（跌倒/血氧过低）

## 5. 数据库

- [ ] health_records / daily_summaries / user_settings 三表
- [ ] 按时间范围查询、按小时/天聚合、异常事件查询、最新记录查询
- [ ] timestamp 索引生效（performance）
- [ ] 90 天清理策略生效

## 6. 通知

- [ ] 通知插件初始化 + Android 渠道 + iOS 权限
- [ ] 跌倒/心率越限/血氧过低通知触发 + 去重

## 7. UI 组件

- [ ] 连接状态栏（设备名/状态/电量/低电量警告）
- [ ] 心率/血氧/步数/运动状态卡片
- [ ] 跌倒告警弹窗（两个按钮样式区分）
- [ ] 趋势图（折线/柱状 + 空状态）

## 8. 权限

- [ ] 权限检查/请求/永久拒绝引导
- [ ] 拒绝后提示

## 9. 集成测试

- [ ] 首次安装→权限→扫描→连接→数据监测
- [ ] 数据存储→图表→报告
- [ ] 断开→自动重连→恢复监测
- [ ] 边界：无设备扫描、连接超时、无数据图表、电量 0

## 10. 发布前

- [ ] 无编译错误/警告（或已评估）
- [ ] 应用图标所有尺寸 / 启动图
- [ ] 应用名称/版本号/包名正确
- [ ] 真机测试通过
