## 1. 目标锚定

- 求职作品：能演示 + 能讲清原理 + 有真实测量证据
- 学原理：嵌入式、BLE 协议、Flutter 跨端、信号处理

**现阶段不做**：产品化（外壳/电池选型/发布认证）、深色主题、大量新功能。

## 3. 缺口清单

### 🔴 高优先级
- [ ] **端到端联调**（手环↔手机，最大未知数）
- [ ] 固件**深度休眠/低功耗**（做"能戴的手表"关键）
- [ ] 固件**RTC 精确时间**（当前纯 NVS，断电期间不计时）

### 🟠 中优先级
- [ ] App **记住设备自动连接**
- [ ] App **后台保活**（Android 前台服务）
- [ ] App **深色主题**
- [ ] 固件**用户设置持久化**

### 🟡 低优先级
- [ ] README 对外展示图（实物/App 截图）
- [ ] 发布素材（图标/包名/签名）
- [ ] 30 天大数据量实测与性能验证
- [ ] 常量去重/代码清理

---

## 4. 下一步优先级

1. **端到端联调**（扫描→连接→收数据→发指令→跌倒弹窗）
2. 固件**深睡 + 中断唤醒**（功耗）
3. App **记住设备自动连接**
4. **讲透原理 + 留证据**（架构图/实测曲线/录屏）
